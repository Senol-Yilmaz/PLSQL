<b>Installation Script</b>
>log4debugInstallation.sql Script were created using Pl/SQL
>
<b>Prerequisite</b>
<ul>
<b>Your Schema must have following grants</b>
<li>grant create any index to "Your Schema";</li>
<li>grant create any procedure to "Your Schema";</li>
<li>grant create any table to "Your Schema";</li>
<li>grant create sequence to "Your Schema";</li>
<li>grant create session to "Your Schema";</li>
<li>grant debug any procedure to "Your Schema";</li>
<li>grant debug connect session to "Your Schema";</li>
<li> and Your Schema user must have dml grants </li> 
</ul>
<b>Also must have select and/or execution permission for the following views </b>
<ul>
<li>SYS.DBMS_APPLICATION_INFO</li>
<li>SYS.DBMS_OUTPUT</li>
<li>SYS.ALL_PROCEDURES</li>
<li>SYS.ALL_SOURCE</li>
<li>SYS.DBMS_UTILITY</li>
<li>SYS.OWA_UTIL</li>
</ul>
